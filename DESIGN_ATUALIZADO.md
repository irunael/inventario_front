# Design Atualizado - Sistema de Gestão de Estoque

## 🎨 Novo Visual: Minimalista e Tecnológico

O design foi completamente redesenhado para um visual mais clean, moderno e profissional, inspirado em plataformas tech como GitHub e interfaces de desenvolvimento.

## 🎯 Paleta de Cores

### Cores Principais
- **Fundo Principal**: `#fafbfc` (cinza muito claro, quase branco)
- **Fundo Secundário**: `#ffffff` (branco puro)
- **Texto Principal**: `#24292e` (cinza escuro)
- **Texto Secundário**: `#586069` (cinza médio)
- **Texto Terciário**: `#959da5` (cinza claro)

### Cores de Ação
- **Primária (Azul)**: `#0366d6` → hover: `#0256c7`
- **Sucesso (Verde)**: `#34d058` → fundo: `#dcffe4`
- **Erro (Vermelho)**: `#d73a49` → fundo: `#ffdce0`
- **Alerta (Amarelo)**: `#ffd33d` → fundo: `#fff5b1`

### Cores de Borda
- **Borda Principal**: `#e1e4e8`
- **Borda Hover**: `#d1d5da`
- **Borda Ativa**: `#0366d6`

## 📐 Elementos de Design

### Tipografia
- **Fonte**: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif
- **Títulos H1**: 24px, peso 600, espaçamento -0.5px
- **Títulos H2**: 20px, peso 600
- **Texto Normal**: 14px
- **Texto Pequeno**: 13px
- **Labels**: 13px, peso 600, uppercase para tabelas

### Espaçamento
- **Padding Containers**: 32px 40px
- **Padding Cards**: 20px
- **Padding Botões**: 8px 16px
- **Padding Inputs**: 10px 12px
- **Gaps**: 4px (pequeno), 12px (médio), 24px (grande)

### Bordas e Sombras
- **Border Radius**: 6px (padrão), 12px (badges)
- **Bordas**: 1px solid #e1e4e8
- **Sombras Leves**: `0 1px 3px rgba(0,0,0,0.12)`
- **Sombras Médias**: `0 4px 12px rgba(0,0,0,0.08)`
- **Sombras Hover**: `0 2px 6px rgba(0,0,0,0.15)`
- **Focus Ring**: `0 0 0 3px rgba(3, 102, 214, 0.1)`

## 🧩 Componentes Atualizados

### Sidebar
- Fundo branco com borda direita sutil
- Itens de navegação com hover suave
- Item ativo com borda esquerda azul
- Ícones com opacidade reduzida

### Botões
- **Primário**: Azul sólido com sombra
- **Secundário**: Fundo cinza claro com borda
- **Perigo**: Vermelho para ações destrutivas
- Todos com transição suave de 0.2s

### Inputs e Selects
- Fundo cinza muito claro (#fafbfc)
- Borda sutil (#e1e4e8)
- Focus com anel azul e fundo branco
- Erro com anel vermelho

### Tabelas
- Cabeçalho com fundo cinza claro
- Texto uppercase e espaçado
- Hover em linhas com fundo suave
- Bordas sutis entre linhas

### Badges de Status
- Uppercase com espaçamento de letras
- Bordas coloridas combinando com fundo
- Tamanho pequeno (11px)
- Peso 600 para destaque

### Cards
- Fundo branco com borda sutil
- Hover com borda azul e sombra
- Padding consistente
- Border radius de 6px

## 🎭 Estados Interativos

### Hover
- Mudança sutil de cor de fundo
- Sombra mais pronunciada em botões
- Transição suave (0.2s ease)

### Focus
- Anel azul de 3px com opacidade
- Borda azul sólida
- Fundo branco em inputs

### Active
- Borda esquerda colorida em navegação
- Fundo cinza claro
- Cor de texto azul

### Disabled
- Opacidade reduzida (0.6)
- Cursor not-allowed
- Cor cinza (#94a3b8)

## 📱 Responsividade

### Desktop (> 1024px)
- Layout de duas colunas
- Sidebar fixa de 220px
- Conteúdo principal fluido

### Tablet (768px - 1024px)
- Sidebar reduzida
- Tabelas com scroll horizontal
- Botões mantêm tamanho

### Mobile (< 768px)
- Sidebar em coluna
- Botões full-width
- Padding reduzido
- Fonte ligeiramente menor

## 🔄 Animações e Transições

Todas as transições usam `ease` com duração de 0.2s para:
- Mudanças de cor
- Transformações de sombra
- Alterações de borda
- Mudanças de fundo

## ✨ Destaques do Novo Design

1. **Mais Limpo**: Menos cores vibrantes, mais tons neutros
2. **Mais Profissional**: Visual corporativo e confiável
3. **Melhor Legibilidade**: Contraste otimizado e tipografia clara
4. **Mais Moderno**: Inspirado em plataformas tech atuais
5. **Mais Consistente**: Padrões uniformes em todo o sistema
6. **Melhor UX**: Feedback visual claro em todas as interações

## 🎯 Comparação Antes/Depois

### Antes
- Cores vibrantes (azul forte, dourado)
- Bordas arredondadas (20-25px)
- Sombras pronunciadas
- Visual mais "colorido"

### Depois
- Tons neutros (cinza, branco, azul suave)
- Bordas sutis (6px)
- Sombras discretas
- Visual mais "tech" e profissional
